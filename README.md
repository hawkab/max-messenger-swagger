# max-messenger-swagger

Преобразователь официальной [документации мессенджера MAX](https://dev.max.ru/docs-api) в привычный разработчику OpenAPI/Swagger-формат.

- Интерактивная документация (Swagger UI): <https://hawkab.github.io/max-messenger-swagger/>
- Готовая спецификация: <https://hawkab.github.io/max-messenger-swagger/max.openapi.yaml>
- Связанный проект: [max-bot-api-java](https://github.com/hawkab/max-bot-api-java) — Java SDK, генерируемый из этой спецификации.

The official MAX messenger documentation converted into the familiar OpenAPI/Swagger format.

[![Поддержать проект · TON network](https://hawkab.github.io/support/support-button.svg)](https://hawkab.github.io/support/)

Необязательные взносы помогают в разработке, сопровождении и тестировании. На [странице поддержки](https://hawkab.github.io/support/) есть QR-код, ссылка на кошелёк и кнопки копирования — работает на компьютере и телефоне. Сумму вы выбираете в кошельке.

Optional contributions support development, maintenance and testing of these tools.
